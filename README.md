# Flight Search Web

> **專案狀態：維修中**

Zeabur 後端已於 2026 年 9 月關閉，目前 Zeabur 帳號內已無本專案。因此，正式 API、機票搜尋、歷史價格、票價追蹤及背景排程目前無法使用。

本次已停止 GitHub Actions 的後端保活排程，並移除前端代理與安全標頭中硬編碼的 Zeabur 網址，避免專案繼續呼叫已不存在的服務或寄送失敗通知。

## 保留內容

- `frontend/`：前端原始碼，供日後維修或重新部署。
- `backend/`：FastAPI 後端原始碼，不綁定 Zeabur，可供日後移轉至其他平台。
- 既有部署與進度文件：僅保留作為歷史紀錄，其中的 Zeabur／Cloudflare 狀態與網址已不代表目前環境。

## 重新啟用條件

重新對外提供服務前，需先選定新的後端部署平台、重新設定環境變數與機密、指定 `FLIGHT_SEARCH_API_URL`，並完成 API、前端及瀏覽器端驗收。
